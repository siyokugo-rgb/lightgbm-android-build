# NAR model contract

## Final objective

最終的にはNARの主要な馬券種について、
各買い目の的中確率を推定し、
券種ごとに推奨買い目を提示する。

対象は以下を想定する。

- 単勝
- 複勝
- 枠複
- 枠単
- 馬複
- 馬単
- ワイド
- 3連複
- 3連単

買い目選択は
「的中重視」「期待値重視」の別モデルには分けず、
的中確率と期待値を別々に推定した上で、
1つのバランス型選択ロジックで行う。

予算指定による購入金額配分は後段で追加する。

## Base prediction

券種ごとに独立した予測モデルを最初から作るのではなく、
各馬の着順に関する確率分布を基礎予測とする。

基礎予測から、

- 1着確率
- 上位2頭の組合せ確率
- 1着→2着の順序付き確率
- 上位3頭の組合せ確率
- 1着→2着→3着の順序付き確率

等を導出し、
各馬券種の的中確率へ変換する。

## Prediction point V1

V1の基準予測時点は、

予定発走時刻の60分前

とする。

ただし過去monthly CSVについて、
その時刻のスナップショットを保持していない項目は、
最終CSVの値を60分前に利用可能だったと仮定しない。

V1では予測時点依存性が小さく、
発走前情報であることを監査できた項目を中心に使用する。

## V1 excluded dynamic features

以下は当日中に変化することを
2026-08-25 live auditで確認したため、
V1では使用しない。

- 人気
- 馬体重
- 馬体重増減
- 天候
- 馬場
- 出走取消・競走除外の発生後情報

これらは将来、
予測時点スナップショットを
学習時と本番時で一致させられる場合のみ追加する。

## Never use as prediction features

以下は結果または結果反映後の情報なので、
予測特徴量として使用しない。

racelist:

- 上がり4F
- 上がり3F
- ハロンタイム1～15
- コーナー通過順1～8

horselist:

- 着順
- タイム
- 着差
- 上がり3F

payback:

- 全項目

これらは教師ラベル、
評価、
馬券バックテスト等の結果側データとしてのみ使用する。

## Training labels

race単位で学習する。

通常の数値着順を
公式結果ラベルとして使用する。

出走取消・競走除外は、
通常の敗戦馬として扱わず、
そのレースの着順学習対象から除外する。

競走中止・失格等で
通常の数値着順が存在しない場合は、
正確な着順を捏造しない。

V1では公式結果状態を以下のように扱う。

- 数値着順:
  正式な順位ラベルとして使用する。
- 同着:
  同一順位をそのまま保持する。
- 出走取消・競走除外:
  その馬の順位教師ラベルを無効とする。
  最終結果上の取消・除外状態を予測特徴量には使用しない。
- 競走中止・失格:
  実際に競走へ参加した馬として扱うが、
  numeric_finish_position は欠損とする。
  win / top2 / top3 は0とする。
- 競走取止め・競走不成立:
  レース全体を教師あり結果学習から除外する。
- 数値着順が1頭もなく全馬が競走除外:
  レース全体をVOID_RACEとして教師あり結果学習から除外する。

2024年5月8日川崎4Rでは、
発走やり直し後に全馬がかなりの距離を走ったため
全馬競走除外・競走取り止めとなった実例を確認した。
このようなケースを個々の馬の通常の競走除外として扱わない。

必要に応じて、

- started
- finished
- win
- top2
- top3
- numeric_finish_position
- order_label_valid

等の別ラベルとして保持し、
着順モデルでの扱いは実験時に決定する。

## Source anomaly policy

以下のsource anomalyを持つ競走は
完全な通常レースとして扱わない。

SOURCE_RESULT_UNAVAILABLE:
racelistとhorselistは存在するが、
結果・払戻を教師ラベルとして利用できない競走。
教師あり結果学習から除外する。

SOURCE_RACELIST_MISSING:
racelistが欠落している競走。
V1学習対象から競走単位で除外する。

SOURCE_HORSELIST_MISSING:
horselistが欠落している競走。
V1学習対象から競走単位で除外する。

PAYBACK_MULTIROW:
異常とはみなさない。
複数の正式な払戻行を保持する。

既存manifestで
SOURCE_NO_RESULT
と記録した218競走は、
観測事実としては
SOURCE_RESULT_UNAVAILABLE
として扱う。
元開催が実際に中止だったか、
結果配信のみ欠落したかまでは断定しない。

## Train / validation / test

ランダム分割は禁止する。

必ず時系列順に分割する。

最初の実験候補:

- train: 2021-2023
- validation: 2024
- test: 2025

2026年データは、
モデル選択後の追加out-of-time評価候補として保持する。

その後、

- 直近3年
- 直近5年
- 直近10年
- 全期間

を比較し、
現在の地方競馬に最も有効な学習期間を決定する。

## Weather

外部気象情報はV1には入れない。

V1完成後に、

- 予測時点までの実測気象
- 直近1/3/6/12/24時間降水量
- 気温
- 湿度
- 風
- 利用可能なら予測時点当時の発走時刻向け気象予報

をPIT条件を守って追加し、
天候なしモデルとの性能差を検証する。

NAR公式の天候・馬場と
外部気象情報は別特徴として管理する。

## Odds and bet selection

基礎モデルは着順確率の推定に専念する。

期待値計算には、
予測時点で実際に取得可能だった
発走前オッズを使用する。

結果後の払戻金を
発走前オッズの代用品として
モデル入力には使用しない。

買い目選択は、

予測的中確率
+
発走前オッズから計算した期待値

を入力とする
バランス型選択ロジックとして実装する。

バランス型選択ロジックは
着順確率モデルとは分離する。

## Development order

1. このmodel contractを固定
2. V1特徴量ホワイトリストを機械可読化
3. 最小学習データ生成器を実装
4. 2021-2025で基礎着順モデルを構築
5. 時系列validation/test
6. 確率calibration
7. 全馬券種の的中確率へ変換
8. 天候特徴を追加してablation test
9. 発走前オッズ取得・保存
10. バランス型買い目選択
11. 予算別購入金額配分
